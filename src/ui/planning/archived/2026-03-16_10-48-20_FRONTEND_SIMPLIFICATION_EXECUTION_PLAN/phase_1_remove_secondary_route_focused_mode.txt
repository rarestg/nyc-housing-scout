Core deliverables
-----------------
1. Remove focused-row adapters/builders from Posts, Review, and Debug.
2. Remove focused loading/error branches that exist only to support the one-row table mode.
3. Remove the focused banner component if it becomes unused.
4. Reuse Listings-style honest off-page behavior:
   - normal table remains paginated
   - deep-linked detail still opens
   - UI makes it clear the selected record is outside the current page
5. Keep route behavior stable for ordinary row selection.

Requirements
------------
- Deep links into `/posts`, `/review`, and `/debug` must still open the right detail drawer.
- Do not synthesize a one-row table to keep the open detail "coherent" with the current page.
- Prefer deletion over new abstraction.
- If a route needs an off-page notice, mirror the Listings behavior rather than inventing a new pattern.

- focused-banner CSS if no longer used
