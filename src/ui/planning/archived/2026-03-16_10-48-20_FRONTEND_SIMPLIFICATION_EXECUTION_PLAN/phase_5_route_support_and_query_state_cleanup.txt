Core deliverables
-----------------
1. Add a small route-local helper in each route for common query/filter updates.
2. Reduce repeated `setQueryState({ page: 1, selectionId: '', ... })` boilerplate.
3. Remove dead code and over-bundled UI from `route-support.jsx`.
4. Keep the durable shared pieces healthy:
   - `useJsonResource`
   - URL builders
   - inspector-link helpers
   - any remaining truly shared pagination or JSON helpers that still earn their keep
5. Avoid extracting new abstractions unless they are tiny and obviously better than the repeated code.

Requirements
------------
- Prefer route-local clarity over clever shared plumbing.
- Do not try to make every route identical.
- Keep URL query-state behavior stable.
- Keep the query-state parsing layer as-is unless a bug forces a small change.

Out of scope
------------
- removing the table library
- major Listings UI redesign
- shell compact/nav changes

Validation
----------
- `npm test`
- `npm run build:dashboard`
- verify route filter changes still:
  - reset page when appropriate
  - clear selection when appropriate
  - preserve URL-driven state
