Core deliverables
-----------------
1. Make the nav rail permanently compact.
2. Delete the nav expand/collapse state and toggle.
3. Remove expanded-nav layout branches from the shell and CSS.
4. Remove Debug's query-param `runId` fallback and keep route-param selection as the canonical path.
5. Merge duplicated compact-table style blocks.
6. Merge duplicated action/link-pill styles if they are materially redundant.

Requirements
------------
- Keep the shell-slot pattern intact.
- Do not redesign the shell visually.
- Do not introduce a new abstraction layer just to hide simple CSS duplication.
- If a shell-context contract trim is helpful, keep it small and surgical.

Out of scope

- route-local query/update helper work
- broad route-support cleanup
- Listings route simplification
